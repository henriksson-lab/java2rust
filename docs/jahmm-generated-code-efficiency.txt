- Existing enum OpdfReaderValue<O> stores a canonical reader handle per variant
  plus an Infallible marker. Its read dispatch boxes the concrete product as Any
  and downcasts to O; an existing fallback only handles selected erased interface
  products. A generic marker retag or additional unchecked From implementations
  would admit a construction without a valid typed product conversion.
- Preferred schema: each eligible variant stores its canonical handle plus typed
  fn(ActualProduct)->RequestedProduct converter for every direct output-binder
  method. Dispatch invokes concrete reader, then converter; Result mapping must
  preserve exceptions. No per-read Any box/downcast. Clone copies handle/function
  pointer without requiring RequestedProduct:Clone. Identity/class/downcast and
  non-product methods continue projecting the original reader handle.

  P:From<ActualProduct>, installing <P as From<ActualProduct>>::from. Identity
  From<T>forT already exists. Source-interface product upcasts need generated
  typed From implementations for the actual canonical source product, using
  existing slot conversions / interface-retarget adapters and upcast pair dedup.
  Reuse erased_interface_retarget_for_hierarchy_return's typed adapter recipe
  without its Any recovery. Audit Rust coherence before emitting broad Froms.

  for owned non-null fixed product producers (the failing OpdfReader group).
  Option/borrowed products must not acquire a premature null check or clone a
  payload. Either map optional success with a converter on its base product, or

  adapters due to coherence. Do not silently enable an unproved nullable case.
