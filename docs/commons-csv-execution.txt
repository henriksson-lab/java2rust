Batch 1: logical text, retained array reads and enclosing-instance receiver

Implemented:
- Character.isWhitespace now selects its own native operation and uses a
  code-point/code-unit Java predicate in java_text.rs. Rust White_Space is not
  Java's predicate. Negative/invalid int code points and isolated surrogates
  return false; the non-breaking-space exclusions and control inclusions stay.
- String.valueOf(char) and String.valueOf(char[]) preserve logical UTF-16 units.
  The char[] overload checks null and reads contents, distinct from Object text.
- Native StringBuilder/StringBuffer.append(char[]) reuses operand staging:
  evaluate receiver/argument, check receiver, read the checked char[] into owned
  JavaUtf16 with a short array loan, then append. No array guard survives into
  the builder call. The snapshot is completed in a let statement so Rust 2021
  tail-temporary destruction cannot outlive the staged allocation owner.
- Numeric char literal assignment uses JavaCodeUnit(u16), including associated
  constant initializers and isolated surrogate constants. The primitive static
  override now consumes the same literal-slot decision.
- Arrays.toString's source logical-text path uses java_arrays_to_text and
  JavaString::from_payload instead of formatting into Rust String. Its leaf
  element protocol preserves JavaString/JavaCodeUnit payloads and null elements.
  java_array_text.rs is emitted with the shared text support, so incidental
  logical String impls never refer to a missing platform-only display trait.
  The old native scalar entry point remains explicit; it cannot encode an
  isolated surrogate. Arbitrary Object callbacks are not falsely admitted to
  this leaf-only display protocol.
- Replaced JavaArraysEqualsInput's borrowed-slice API with JavaArrayReadInput:
  length/nullness, identity and per-element canonical reads for slices, Vec,
  optional values, Rc<RefCell<Vec>> and Arc<Mutex<Vec>>. Equality releases both
  loans before comparing each element, preserves null/equal-allocation fast
  paths and observes later element writes after callbacks. Logical array
  display and retained array hashing reuse that reader. No detached whole-array
  snapshot or borrowed slice behind a dropped lock is introduced.
- Added logical String comparison/hash leaves for those array operations.
- Receiver usage now counts qualified Outer.this as a read of the current
  object's capture. The private-receiver-elision proof therefore retains the
  receiver for CSVRecordIterator.getNextRecord's outer-only body; signatures,
  call sites and emitted bodies share that usage evidence.
