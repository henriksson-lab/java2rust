   Unknown evidence is not permission to move. Removed obsolete emitted-text
   constructor clone deletion. Required reference copies happen before consuming
   nullable/upcast conversions; canonical copies remain separate from Java clone.

   tokens in src/plan_contracts.rs. Invalid modeled obligations become Errors

   SlotConversionPlan and selected target through a frozen boundary.

3. Added solver-owned GenericParameter slots even for owners with no direct
   declaration occurrence. Generic qualifiers saturate through existing edges;
   artifact construction reads the solved result. Removed the production second
   ancestor fixedpoint and post-saturation qualifier repair.

4. Added src/generic_allocation_schedule.rs: indexed, stable, synchronous
   execution of one existing allocation propagation arm. Watches destination
   normalization prerequisites too; other arms still use global saturation.
   Complete closure/final-plan equivalence against the reference arm is tested.

5. Added src/representation_solver.rs: bounded deterministic heuristic CSP with
   hard compatibility tables, additive costs, pruning, component-local search
   and a feasible incumbent. No ILP/CSP dependency added. Real production pilot
   in src/canonical_transport_optimizer.rs borrows canonical handles for proved
   private static scalar observers, keeping storage/dispatch/results fixed.
   Existing physical parameter ABI is finalized in SignaturePlan before search;
   both indices, body inference, emission and calls agree on selected loans.

6. Fixed scoped nominal/binder identity using existing binder-aware substitution
   and a shared capture-avoiding catalog (src/scoped_type_parameters.rs). An
   unrelated Unrelated<Cell> previously made aliased nominal Cell use payload
   copies: baseline Rust printed0, Java7. The global storage exclusion is gone.
   Primary/context/summary/resolver copies use consistent identities before facts.
   Exact value method references follow lexical namespace precedence.

7. Repairs exposed by verification:
   - All nine Rc/Arc/Weak copies in java_native_reference.rs use typed Rust Clone
     UFCS, avoiding Java interfaces' clone() ambiguity and preserving owners.
   - Nullable erased Object-to-String casts use the existing borrowed checked
     canonical-reference conversion, with the actual String runtime type.
   - Nullable source upcasts copy a later-used canonical handle BEFORE .map/Into.
   - Shared/mutable optional local loans from proved owned temporaries retain
     the backing owner, including receiver-only uses. This fixes a dangling
     Option<&mut dyn Trait> into a dropped Box; no staging reborrow workaround.

Architectural limits / possible next work

This was the initial bounded refactor, not a universal Java-to-Rust CSP engine.
Frozen coverage includes generic qualifier relations and selected initializer
boundaries. Arbitrary assignments/calls/returns, virtual adapters and every local
physical refinement are not globally frozen. Heuristic candidates remain narrow
and admitted by existing implementations; lower source score alone proves nothing.

Conditional extensions from the plan remain conditional: reusable callback/
reentry effects before guard coalescing, live generic collection/array view
protocols before admitting retained retargeting, and escape/flow proofs before
nominal allocation-context splitting. No such new transformations were attempted.
Type-only method references through a renamed binder are explicitly unsupported;
proven value-qualified references are preserved. Existing JavaMonitor reentrancy
is distinct from payload Mutex behavior and remains unchanged.
